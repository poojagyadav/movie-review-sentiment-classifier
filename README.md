# IMDB Sentiment Analysis Using RNN

This is an educational project that uses a Recurrent Neural Network (RNN) with PyTorch to classify IMDB movie reviews as positive or negative.

## Project files

- `RNN_for_sentimentanalysis.ipynb` — notebook containing the project code.
- `IMDB Dataset.csv` — movie reviews and sentiment labels used by the notebook.

## Requirements

- Python
- Jupyter Notebook
- PyTorch
- pandas
- scikit-learn

Install the required packages:

```bash
pip install torch pandas scikit-learn jupyter
```

## Run the project

1. Open the project folder in your terminal.
2. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

3. Open `RNN_for_sentimentanalysis.ipynb`.
4. Run the notebook cells in order.
